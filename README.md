## 定位
Samiyah Digital 是面向全球各行业客户的独立数字科技服务品牌，提供网站建设、App 开发、企业软件、人工智能解决方案、数字创意、数字营销及相关数字化服务。

英文定位建议：**Digital Products, AI & Business Technology Solutions**  
首页主标题建议：**Digital Solutions for Every Industry**

## 独立性与公开内容规则（已确认）
1. 本仓库仅记录 Samiyah Digital 的业务、产品、网站、技术、设计、运营与项目决策。
2. 与其他业务的客户、服务、特殊合作政策及资料分离；不在官网公开其他业务的内部权益或赠送规则。
3. 官网面向所有行业，不以任何单一行业作为品牌主视觉、示例主题或核心定位。
4. 官网不得出现未经核实的真实客户 Logo、案例、项目数量、满意率、国家数或认证；演示必须标记 Demo。
5. 顶部菜单保持精简：**Home / Services / Industries / Projects / About**；右侧为 **Language / Client Login / Start a Project**。
6. 公开官网、客户门户、项目交付和 AI 后台分层建设；租户数据隔离、权限与审批机制优先。
