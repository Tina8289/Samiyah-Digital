日期：2026-11-16｜状态：Draft（待页面级评审）

## 已确认边界
- 独立数字科技业务，面向所有行业；不出现卫浴业务内容、免费赠送政策或内部合作权益。
- 顶部导航固定五个一级菜单：**Home / Services / Industries / Projects / About**。
- 右侧独立操作：语言切换、Client Login、Start a Project。
- 视觉方向：深海军蓝 + 紫蓝渐变 + 白色内容区；高端、国际化、响应式。
- 不使用未经证实的客户 Logo、统计、合作品牌、认证或案例；演示案例必须标注 Demo。
- 以下三级是“一级导航 → 二级栏目 → 三级内容/页面”，并不要求每个三级条目都有独立 URL。

## SEO/GEO/AEO 与技术基线
语义化标题、唯一主意图、可抓取页面、canonical、sitemap、结构化数据（有对应真实内容时）、内链、国际化 hreflang 策略、Web Vitals、移动端优先与无障碍。禁止为了凑 URL 生成重复薄内容。动态服务和行业内容应引用统一 CMS 数据源。
